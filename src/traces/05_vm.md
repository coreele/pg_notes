# VM

观测 Visibility Map 置位 / 清位，以及 Index Only Scan 是否因此免访堆。机制见 [Why & How: VM](../backend/access/heap/01_vm.md)；计划形态见 [Index Only Scan](../backend/access/nbtree/01_plan.md)。

- 调试：`VACUUM tb` 前后 `EXPLAIN (ANALYZE) SELECT a FROM tb WHERE a = 5432` 的 **Heap Fetches**
- 依赖：contrib `pg_visibility`
- 表上 `autovacuum_enabled = off`，单会话、不要另开未提交事务（oldest xmin 过老则无法标 all-visible）

## 调用链

**VACUUM 置位**（持堆页锁）：

```text
VACUUM 扫堆页、必要时 freeze
  -> 确认全可见 / 已冻结
  -> visibilitymap_pin（无堆锁，可 I/O）
  -> 锁堆页、复核
  -> 置 PD_ALL_VISIBLE
  -> visibilitymap_set → log_heap_visible
```

**DML 清位**（与堆页修改同一临界区）：

```text
heap_insert / heap_update / heap_delete / heap_lock_tuple
  看堆页（尚未加锁）：若 PD_ALL_VISIBLE → visibilitymap_pin
  锁堆页
    若其间 VACUUM 刚置位而 VM 未 pin → 放锁、pin、再锁
  改 tuple + XLogInsert
    同一临界区 visibilitymap_clear
```

**Index Only Scan**：

```text
IndexOnlyNext
  -> 索引取 TID
  -> visibilitymap_get_status
       all-visible -> 不再访堆（仍持有索引叶 pin）
       否则 heap fetch + HeapTupleSatisfiesVisibility
```

## 准备

```sql
CREATE EXTENSION IF NOT EXISTS pg_visibility;

DROP TABLE IF EXISTS tb;
CREATE TABLE tb (a int, b bigint) WITH (autovacuum_enabled = off);
INSERT INTO tb SELECT n, n FROM generate_series(1, 100000) AS n;
CREATE INDEX idx ON tb (a);
ANALYZE tb;
```

数据已提交，VACUUM 未跑，VM 仍为 0（保守）。

```sql
SELECT pg_relation_filepath('tb') AS main,
       pg_relation_filepath('tb') || '_vm' AS vm_fork;

SELECT * FROM pg_visibility_map_summary('tb');
-- all_visible | all_frozen  均为 0（或 _vm 尚不存在）
```

## VACUUM 前：IOS 仍回堆

```sql
SET enable_seqscan = off;
EXPLAIN (ANALYZE, COSTS OFF)
SELECT a FROM tb WHERE a = 5432;
```

期望：`Index Only Scan`，**`Heap Fetches: 1`**。

## VACUUM 后：VM 置位，免访堆

```sql
VACUUM (VERBOSE) tb;

SELECT * FROM pg_visibility_map_summary('tb');
-- all_visible ≈ relpages，all_frozen 仍可能为 0

SELECT blkno, all_visible, all_frozen, pd_all_visible
FROM pg_visibility('tb')
LIMIT 5;
-- VM all-visible 与堆页 PD_ALL_VISIBLE 应一致

EXPLAIN (ANALYZE, COSTS OFF)
SELECT a FROM tb WHERE a = 5432;
```

期望：**`Heap Fetches: 0`**。再 `VACUUM (VERBOSE) tb`，scanned / skipped 会显示大部分页被 VM 跳过。

`pageinspect.page_header(...).flags` 的 `PD_ALL_VISIBLE` 为 `0x0004`，可与 `pd_all_visible` 交叉验证。

## UPDATE：只清被改的堆页

```sql
UPDATE tb SET b = b WHERE a = 5432;

SELECT blkno, all_visible, all_frozen, pd_all_visible
FROM pg_visibility('tb')
WHERE NOT all_visible OR NOT pd_all_visible;

EXPLAIN (ANALYZE, COSTS OFF)
SELECT a FROM tb WHERE a = 5432;
-- Heap Fetches 回到 1

EXPLAIN (ANALYZE, COSTS OFF)
SELECT a FROM tb WHERE a = 1;
-- 未改动的页仍是 0
```

## FREEZE：all-frozen

```sql
VACUUM (VERBOSE, FREEZE) tb;
SELECT * FROM pg_visibility_map_summary('tb');
-- all_frozen 升到接近 all_visible
```
